# XPath Task 2.2 – Login Page Elements

## Eingabefelder

```xpath
//input[@type='email']
```

```xpath
//input[@type='password']
```

## Sign In Button

```xpath
//button[@type='submit' and contains(text(),'Sign In')]
```

## Create a new account

```xpath
//a[contains(text(),'Create a new account')]
```

## Go to Home

```xpath
//a[contains(text(),'Go to Home')]
```
